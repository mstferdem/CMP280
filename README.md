# FitType – Personalized Fitness & Nutrition Application

## Project Overview

FitType is a fitness and nutrition application designed to help individuals achieve their health and fitness goals through personalized workout recommendations, nutrition tracking, and progress monitoring.

This project was developed as part of the CMP280 Software Engineering course at County College of Morris (CCM). It focuses on applying software engineering principles throughout the planning, requirements analysis, and system design phases of the Software Development Life Cycle (SDLC).

## Project Objectives

- Provide personalized workout recommendations based on users' body types and fitness goals.
- Simplify calorie tracking and nutrition management.
- Help users establish and monitor their fitness goals.
- Design an intuitive and user-friendly application.
- Apply software engineering methodologies to a real-world problem.

## Proposed System Features

- **Personalized Workout Plans:** Exercise recommendations based on individual body types and fitness objectives.
- **Calorie Tracking:** Monitoring daily calorie intake and nutritional information.
- **Image-Based Food Recognition:** Identifying food and estimating nutritional values from uploaded photographs.
- **Progress Tracking:** Monitoring users' fitness goals and physical progress.
- **Healthy Recipe Recommendations:** Providing meal suggestions aligned with users' nutritional goals.
- **Calorie Limit Notifications:** Notifying users when they approach or exceed their daily calorie targets.
- **Device Integration:** Optional integration with smartwatches and smart scales.
